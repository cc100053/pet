Description
PetTomo（ペットモ）は、あなたの「写真」がペットのご飯になる、世界初のソーシャルペット育成ゲームです！

日常の何気ない一枚が、ペットとの魔法のような瞬間に変わります。PetTomoはただのゲームではありません。友達やパートナー、家族と一緒に、世界に一匹だけのデジタルパートナーを育てる共有体験です。

主な特徴：

写真で餌やり：ボタンを押すだけじゃつまらない！カメラで実物を撮影してペットにあげましょう。コーヒーの写真で目を覚ましてあげたり、お花の写真で喜ばせたり。AIペットがあなたの写真を理解します！
シェアルーム：部屋を作って友達を招待しよう。一緒にペットのお世話をしたり、部屋をデコレーションしたり。誰が一番お世話上手かな？
AI インタラクション：スマートなペットは、あなたが見せたものを認識します。撮影したものによって異なるリアクションや、特別な報酬が見つかるかも。
成長を見守る：タマゴからスタートして、様々な段階へと進化します。あなたのお世話の仕方で、ペットの見た目や性格が変わります。
ソーシャルログ：最高に楽しい瞬間を記録に残そう。毎日の餌やり写真が、大切な共有アルバムになります。

今すぐPetTomoに参加して、あなただけのパートナーを育て始めましょう！
