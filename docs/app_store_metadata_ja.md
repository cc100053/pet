### Description
ペットモ (PetTomo) は、あなたの「日常」がペットの「ごはん」になる、共有型育成ゲームです。

恋人や友達と同じ部屋に入り、1匹のペットをふたりで育てましょう。写真を撮って、チャットして、部屋を飾って。何気ない毎日が、かけがえのない思い出に変わります。

**ふたりで育てる、共有ペット**
パートナーや親友を招待して、育成スタート。ごはんをあげるのも、掃除するのも、なでるのも、すべてリアルタイムで共有されます。遠距離恋愛中のカップルにもぴったり。

**写真でごはん**
ランチの写真、空の写真、笑顔の写真。カメラで撮った日常が、ペットのエネルギー (XP) になります。写真は「思い出アルバム」として残り、二人の交換日記のように楽しめます。

**癒やしの空間**
共有ルームではリアルタイムチャットが可能。相手が送った「ごはん写真」にリアクションしたり、お揃いの家具を置いて部屋をコーディネートしたり。二人のだけの居場所を作りましょう。

**成長を見守る**
愛情を注いでペットをレベルアップさせましょう。二人の絆と共に、ペットもどんどん成長していきます！

**こんな方におすすめ：**
- 恋人との繋がりを感じたい方。
- 遠距離恋愛 (LDR) で、共通のルーティンが欲しい方。
- 友達とゆるく繋がれる癒やしのアプリを探している方。
- 忙しいけれど、何かを育てる喜びに浸りたい方。

**注記：**
現在のバージョンでは、写真ラベル認識機能はベータ版です。認識しない場合でも、手動入力で楽しく餌やりができます！
