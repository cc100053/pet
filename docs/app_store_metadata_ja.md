Description
ベットモは、毎日の「写真」がペットのお世話と思い出になる、ソーシャル育成アプリです。

友達、パートナー、家族と同じ部屋に集まり、1匹のペットを共同で育成。写真でごはんをあげて、リアルタイムチャットでやりとりしながら、いっしょに成長を見守れます。

主な特徴：

共同育成：みんなで1匹を育てるから、毎日の小さな変化がもっと楽しい。  
写真でお世話：カメラやライブラリの写真で、ペットとのふれあいが進む。  
リアルタイム交流：チャットで気軽に会話しながら、成長を共有できる。  
育成とカスタマイズ：レベルアップ、部屋の装飾、コレクション要素も充実。

重要なお知らせ：
現在のバージョンでは、写真ラベル認識機能は一時的に利用できません。写真を使った餌やり機能は通常どおり利用できます。

今すぐベットモで、いっしょに育てる毎日を始めましょう。
