### Description
PetTomo 是把「照片互動」與「社交共養」結合在一起的寵物養成 App。

和朋友、另一半或家人加入同一個共享房間，一起照顧同一隻寵物。你可以用相機或相簿照片餵食，透過聊天室即時互動，並且一起見證寵物每天的成長。

核心特色：

共同養成：多人一起照顧同一隻寵物，陪伴感更強。  
照片餵食：用生活照片和寵物互動，日常也能變成遊戲樂趣。  
即時社交：聊天室即時互動，分享每次餵食與成長時刻。  
成長與佈置：寵物升級、房間裝飾、收藏元素一次滿足。

重要說明：
目前版本暫時無法使用「照片標籤辨識」功能，但拍照/選圖餵食功能仍可正常使用。

現在就加入 PetTomo，開始你們一起養成的可愛日常。
