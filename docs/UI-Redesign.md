## 2. UI/UX 設計詳解 (New UI Design)
本章節基於新版 UI 設計圖進行詳細說明。

![新版 UI 設計圖](/Users/fatboy/pet/memory-bank/ui-redesign.png)

### 2.1 啟動頁 (P.1 Launch)
- **佈局**: 簡潔的白色背景，中央放置 App Logo。
- **功能**: 
  - 應用程式啟動。
  - 自動登入檢測。
  - 轉場至 P.2 房間選擇頁。

### 2.2 房間選擇/主頁 (P.2 Room Selection)
- **頂部導航**:
  - 左上角：[我 (Me)] 頭像按鈕，點擊開啟側邊選單 (Drawer) 或個人設定。
- **核心區域**:
  - **Grid 佈局**: 顯示現有的寵物/房間卡片 (2x2 或更多)。
  - **卡片內容**: 顯示寵物頭像、名稱、狀態概覽 (如心情燈號)。
  - **空缺位**: 顯示 "+" 號或空置狀態。
- **底部操作**:
  - **[養新寵物] 按鈕**: 顯眼的 CTA (Call to Action) 按鈕。

### 2.3 寵物互動主畫面 (P.3 Interaction)
- **頂部導航**:
  - 左上角：[我 (Me)]。
  - 右上角：[日曆 (Calendar)] 圖標，點擊跳轉至 P.4 回憶錄/日曆頁。
- **核心區域 (分層顯示)**:
  - **上方區塊 (照片/Photo)**: 展示最新的餵食照片。
- **下方區塊 (寵物的家/Pet Home)**: 寵物動畫所在的互動區域 (Idle: Lottie / Walk: GIF)。
- **底部操作欄**:
  - 三個主要圓形按鈕 (功能待定，預計為：餵食、互動/摸頭、清潔)。


### 2.4 回憶錄/日曆 (P.4 Calendar/Journal)
- **進入方式**: 從 P.3 右上角日曆圖標進入。
- **頂部**: 
  - 月份顯示 (e.g., January)。
  - 星期列 (SUN - SAT)。
  - 日期氣泡連線 (Habit Tracker 風格)。
- **今日摘要 (Today)**:
  - 顯示 "最新的照片"以及關於照片嘅描述。
- **底部列表**:
  - 前一張照片, 前一張照片嘅描述, 再前一張照片, 再前一張照片嘅描述...總共有三張照片

### 2.5 側邊欄/歷史記錄 (P.5 Drawer/History)
- **佈局**: 
  - 側邊滑出或獨立頁面。
  - 時間軸風格式的列表。
  - 顯示 "最新的照片" 縮圖與文字記錄。

## 3. 核心玩法規則 (Gameplay Rules)
*(保留原 v2.0 核心邏輯)*

### 3.1 寵物生成
- **Color DNA**: 根據餵食照片的主色調決定寵物顏色。
- **成長**: 隨時間與互動次數長大。

### 3.2 數值系統 (Stats)
- **飽食度 (Hunger)**: 隨時間自然消耗，餵食補充。
- **心情 (Mood)**: 
  - Low -> Mid -> High -> Sad (生病)。
  - 互動 (摸頭/餵食/洗澡) 可提升心情。
- **清潔度 (Hygiene)**: 定期產生大便，不清理會扣心情。

### 3.3 經濟系統 (Economy)
- **金幣**: 透過餵食、摸頭、清理獲得。
- **冷卻**: 每個動作每小時限獲獎勵一次。
