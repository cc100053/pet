# Turtle walk trial v4: prompt plus pose guide

Prepared on 2026-10-05 at the owner's request, as an AI alternative alongside the
[cut-out rig](../../rig/README.md). Earlier prompts described the poses only in words
and never produced crossing legs. This trial attaches a drawn pose for every frame.

- [Pose guide](pose_guide.png): 1350 × 1350, 3 × 3 grid. Generated by
  `python3 rig/pose_guide.py` from the rig's walk poses, with the foot lift
  exaggerated so it reads at sheet size. Grey is the body, dark grey the shell,
  light grey the arms, blue the image-left leg, orange the image-right leg (drawn
  in front where they overlap) and green the tail. Frame 9 repeats frame 1.
- [Prompt](prompt.txt). Attach the [selected master](../../selected_master.png)
  as image 1 and the pose guide as image 2, in a NEW Gemini chat.

Each step uses the contact, passing and contact poses. The image-right leg
swings in frames 2-4 and crosses in front of the image-left leg in frames 4-6.
The image-left leg swings in frames 6-8. The blink is half-closed on frame 3
and closed on frame 4. The prompt also gives the master's colour values.

The result has not been generated yet. Split and review it as in v3, check that
the legs really cross, and run the colour match if the colours drift.
